Methodology and limits

Synthetic seeded models/inputs; synchronous session.run; perf_counter_ns; warmup excluded. Shared systems are noisy. No production task accuracy or physical board validation.

Each inference uses the same prepared input. CPU frequency, thermal effects, graph caching and other activity can affect timings. Stress retains bounded first samples per worker; their percentiles may not represent the entire run. Sequential benchmarks include Python call overhead; stress throughput is concurrent. GPU selection alone does not prove accelerator node execution. Boundary RSS snapshots do not establish peak memory. Synthetic numerical agreement establishes runtime fidelity, not task accuracy. No physical development board testing was performed.
